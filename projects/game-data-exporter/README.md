# Export Schedule I game data

This directory owns the source for NeonSchedule1's local game-data tools.
It is separate from the TypeScript workspace and future website runtime.

The exporter reads only an explicit project-owned schema.
Raw exports, game files, assemblies, decompiled code, saves, player or organization names, Steam identifiers, and unrelated save state must not enter the repository.

See [Set up the game-data exporter](/docs/exporter-development-setup.md) for the required local tools.
