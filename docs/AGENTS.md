# Public documentation

These rules apply to public Markdown in this directory and to the root README that links here.

- Write for players, contributors, and visitors who start with no project context
- Separate current usable behavior, contributor tooling, and planned work
- Keep internal planning, agent activity, private infrastructure, and unresolved discussion out of public pages
- Link to repository files with root-relative paths that begin with `/`
- Put each prose sentence on its own source line and separate paragraphs with a blank line
- Use sentence-case headings and direct language
- Use no em dashes or semicolons
- End list items without periods

The root README owns purpose, availability, and navigation.
